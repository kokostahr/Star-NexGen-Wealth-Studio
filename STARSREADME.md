I redesigned the entire website aesthetic and UI, mainly inspiried by dark-themed websites and applications I have come across.
I avoided using bright colours, mainly to reduce eye strain (for myself) and build an interface that looks and feels cohesive.

NB!! ABOUT LOGIN/SIGNUP
the authentication system for the website is a ui mock and doesnt have any real backend logic. So, you can sign up 900 time with the same emai or even login without ever signing up and its on purpose (for now).
the login/signup and profil pages are built to give the feeling of a 'real' user account but all the data is stored in localStorage. so it lets usars save their activity without actually needing a server.
Just to add to that, the usar's activity saves to the localStorage only AFTER signing up/ loggin in, as i centred all the logic around an isLogged in state.
